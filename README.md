# KelanaAI

KelanaAI is a travel planning project that is being developed as part of the Web Developer Advanced Program - Phase 2.

## Session 1 - Trip Summary Generator

In the first session, I built a simple Trip Summary Generator using Python as a console application.

The program asks the user to enter:

- Destination
- Country
- Days
- Budget
- Currency
- Travel Month

After all the information is entered, the program displays the trip summary in a simple and readable format.
